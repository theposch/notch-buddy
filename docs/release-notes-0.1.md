# Notch Buddy 0.1

The first public release.

## What's in it

- **Sessions in the notch.** Every Claude Code session, what it's doing, and which ones need you. Allow, Deny or Always right from the notch, or jump to the conversation.
- **Messages on the closed notch.** "Run npm test?", "Tests failed", "Plan ready", "Back at 7:00 PM" and more. Choose which ones you see in Settings > Messages, with presets and your own limits.
- **Usage left.** Your 5-hour and weekly limits, from Claude Code's status line, or (if you switch it on) from the login Claude Code or the Claude desktop app already has on your Mac.
- **Several accounts.** Each Claude account gets its own name and colour; sessions show which one they're on, and you choose whose usage the closed notch follows.
- **Clawd reacts.** Cheers for passing tests, merges and big changes; sweats when usage runs low; naps when it runs out.
- **Fits your screen.** On a MacBook the usage stays clear of the camera; other screens get a smaller notch.

## Good to know

- Reading a login is off until you switch it on, and macOS asks your permission first. Logins are kept in memory only and only sent to Anthropic.
- If this copy isn't signed with a Developer ID, macOS will ask again for Keychain access after each update.
